## Universal

### Project Name

EvidenceOps Agent

### Tagline

Explainable AI incident response with evidence timelines, multi-agent reasoning, and human approval gates.

### What It Does

EvidenceOps Agent is an AI incident response workspace for security teams. It turns fragmented alerts from identity, OAuth, endpoint, storage, DLP, proxy, backup, and developer systems into a clear investigation packet.

The demo supports three replayable scenarios: OAuth token theft, ransomware prelude, and insider exfiltration. For each scenario, the agent builds an evidence timeline, generates a risk score, explains the reasoning behind the score, creates a human approval queue for high-impact response actions, and drafts an incident report that can be copied or downloaded.

### Inspiration

AI-driven attacks move faster than traditional incident response. Human analysts still need to gather logs, reconstruct timelines, explain confidence, and decide which containment actions are justified. EvidenceOps Agent is designed as the analyst cockpit for that moment: fast enough for agentic response, but explainable enough for a human to trust.

### How We Built It

The current prototype is a static HTML, CSS, and JavaScript application using mock security telemetry. The data model separates alerts, evidence timeline events, scoring rules, approval gates, and response steps. The interface renders the investigation as an analyst workspace with a left alert feed, central evidence timeline, right-side agent reasoning, and a report panel.

The architecture is intentionally easy to extend: the mock telemetry can be replaced with Splunk searches, SIEM results, MCP tools, or endpoint triage outputs without changing the user workflow.

### Challenges

The main challenge was balancing automation with trust. An incident response agent should not blindly revoke accounts or block file servers just because a model says so. The prototype therefore separates agent reasoning from human approval gates and keeps evidence references visible.

Another challenge was creating a demo that works without requiring judges to configure cloud credentials. The current app is runnable as a static site, while the architecture and documentation describe how it would connect to Splunk, SIFT, MCP tools, or ticketing systems.

### Accomplishments

- Built a complete incident response dashboard that runs locally or as a static deployment.
- Added three security scenarios for stronger judging demos.
- Added explainable scoring, evidence timelines, generated reports, and approval gates.
- Created a submission pack, deployment guide, screenshot, and demo script.

### What We Learned

Agentic security tools need more than speed. They need clear evidence handling, bounded action permissions, and audit-friendly explanations. The most compelling workflow is not "AI replaces the analyst"; it is "AI reconstructs the case quickly and lets the analyst approve the risky steps."

## Splunk Agentic Ops Hackathon

### Track

Security.

### Splunk Positioning

EvidenceOps Agent is designed as an agentic SecOps layer on top of Splunk data. In the production version, each scenario input would be generated by Splunk searches across identity, OAuth, endpoint, storage, DLP, proxy, backup, and developer telemetry. The agent workflow would use Splunk MCP Server or Splunk APIs to retrieve events, group them into an evidence timeline, score the incident, and draft response steps.

### How It Uses AI

The prototype simulates the AI reasoning layer with deterministic scoring rules so judges can inspect the workflow without external credentials. The intended AI layer performs three tasks: evidence collection, threat assessment, and response drafting. These map naturally to Splunk AI capabilities and agentic workflows.

## Band of Agents

### Track Fit

Regulated & High-Stakes Workflows or Internal Enterprise Workflows.

### Multi-Agent Framing

EvidenceOps Agent is a coordinated multi-agent incident response workflow:

- Evidence Collector: gathers and normalizes alerts.
- Threat Assessor: scores the case and maps the attack sequence.
- Response Drafter: writes a report and action plan.
- Approval Coordinator: separates high-impact actions from fully automated steps.

### Why It Fits

Security incident response is high-stakes enterprise work. The demo shows agents exchanging context, coordinating a shared timeline, and escalating risky actions to a human approval queue.
