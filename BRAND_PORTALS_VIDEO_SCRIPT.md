# Brand Portals 60-90 Second Video Script

Use this only if the Brand Portals submission form asks for a video or if adding a short walkthrough is allowed.

## Video Title

EvidenceOps Agent Brand Portal Walkthrough

## Target Length

60-90 seconds.

## Recording Setup

- Open: https://1kai123.github.io/evidenceops-agent/brand-portal/
- Use a desktop browser window.
- Keep the cursor movement slow and deliberate.
- Do not show passwords, email inboxes, Devpost settings, or personal student information.

## Shot List

1. Start on the Brand Portal hero.
2. Show the product promise: `Evidence that moves at machine speed and still stands up in review.`
3. Scroll to `Judge Fit`.
4. Pause on the five criteria: presentation, organization, design quality, consistency, completeness.
5. Scroll to the asset library and show the logo/download cards.
6. Scroll to the application examples and voice section.
7. End on the submission package / BrandKity transfer area.

## Voiceover

EvidenceOps Agent is an explainable AI incident response workspace, and this is its Brand Portal.

The brand promise is simple: evidence that moves at machine speed and still stands up in review.

Instead of a generic AI look, the identity uses the language of security operations: incident reports, evidence IDs, terminal traces, approval gates, and careful uncertainty labels.

This portal is built directly around the Brand Portals judging criteria. Presentation is handled through a clear first-screen story. Organization is handled through separate sections for assets, visual system, applications, voice, and submission package. Design quality comes from a security-native visual system. Consistency is shown across logo, report, social, and product examples. Completeness is shown through the live portal, source assets, downloadable package, QA report, and BrandKity transfer guide.

The kit includes SVG logos, a PNG Devpost cover, social assets, color and typography rules, voice examples, brand guidelines, and a downloadable asset package.

EvidenceOps Agent is not branded as magic automation. It is branded as fast, traceable incident response that analysts can defend.

## Caption / Description

EvidenceOps Agent Brand Portal: a complete security-native identity system for an explainable AI incident response workspace, with live portal, logo suite, downloadable assets, voice rules, QA proof, and direct mapping to the Brand Portals judging criteria.
